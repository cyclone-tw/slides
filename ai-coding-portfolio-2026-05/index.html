Personal Workflow Control Plane

CycloneOS：從本地 Dashboard 轉向雲端 AI 工作流控制台

目前主要功能定位

  • 整合個人 Gmail、Google Drive 與 OpenClaw 產出的內容。
  • 從本地 dashboard 逐步轉成雲端可用的工作流控制台。
  • 透過 OpenAB 串接 agent / executor / GitHub / Discord 的工作流程。
  • 具備 React Flow 節點式 Pipeline，可以拉節點組出資料處理與輸出流程。

這兩個月完成的工程推進

  • Pipeline Workstation：節點 inspector、input / output adapters、graph validation、resume、approval。
  • Obsidian / Google Drive publish execute E2E：預覽、安全審核、寫入邊界。
  • DOCX / Mac executor pipeline：template render、artifact metadata、OpenAB contract。
  • Finance Workstation：記帳資料、幣別、狀態、summary filters 與 UI polish。

Management Method

用 issue / PR 管理 AI coding，而不是只靠聊天記憶

這是 AI coding 能規模化的關鍵

  • 每個功能、修復、部署與 runtime 變更，都先落到 issue。
  • PR 對應 issue，讓 CTO / 協作者能看懂需求脈絡與驗收條件。
  • OpenAB 再把 PR watch、review、Discord thread 串起來，形成可追蹤循環。
  • 結果是：AI 可以快速寫 code，但流程仍保有工程治理。
