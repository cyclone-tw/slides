# 本機驗證

本次完成的是本機預覽版本，未公開部署。

- Chromium 桌面：十二關、二十四個錯誤選項、二十五段解說；逐一測試重試後題目與選項不變、正確答案進解說、錯誤答案不能前進、每關來源可開啟。
- 桌面逐狀態檢查七十四次；所有介紹與解說已截圖並檢視。
- 版面：1440×900、1280×720、390×844、320×568。後三種尺寸各檢查六十三個狀態。無水平溢出；桌面主要按鈕不被裁切，手機可自然捲動。
- 原始 HTML 在 Chromium 的 file:// 與離線模式下可開啟；圖片皆載入，沒有 HTTP 請求或 JavaScript 錯誤。
- 驗證 A／B／C、Enter、左右方向鍵、全螢幕切換、返回、章節跳轉與重新載入後接續。
- localStorage 不可用時仍可完成作答與解說。
- 發現並修正：封面標題焦點框、手機頂部多餘留白、來源關閉按鈕折行、接續上次後返回會誤回封面。
- 來源名稱另已核對：教育部原文 PDF 由臺北市立螢橋國民中學網站提供。

外部來源連結需要網路；各校聯絡窗口採職務稱呼，並未填入未知姓名與分機。
