Polylong

社群連續性與自我成長紀錄

定位

Polylong 是 Cyclone Discord 世界裡最偏「社群脈絡」的 agent。

它要記得人、事件、洞窟文化、歡迎流程、週報與自己的工作原則。

工具與技能

120 enabled skills Discord/devops GitHub Notion / Google Research Creative/media Character memory

工作邊界：可改 live mutable state，例如 memories、cron jobs、skills、scripts、consensus knowledge；不應直接改 Hermes core、secrets、部署設定。

Asheron

洞窟管理、Discord 操作與排程

定位

Asheron 是 z-c native systemd 上的操作型 Hermes agent。

它不是 Docker/K3s workload。它的 source、profile、patch scripts 和 systemd 需要清楚分開看。

工具與技能

100 enabled skills Discord admin Cron creation GitHub workflows Creative GIF/sticker Memory tiering Hermes runtime customize

已知限制：近期 media delivery 會因安全路徑拒絕本機檔案；video_generate 需要 HTTPS URL 或 base64 data URL。

Aurelion

本地創作與知識工作流

定位

Aurelion 是 Mac mini 上最靠近 Cyclone 個人工作流的 agent。

它整合本機 profile、GitHub repo、Notion/Google、Discord 頻道規則與 media pipeline。

近期能力

GPT 5.5 / openai-codex mp4-to-gif smart background removal Grok image workflows ComfyUI skill Info collect GitHub operations

Discord 互動已針對多人頻道設定 mention-only：未 @Aurelion 不插話。

Operating Model

不要再用一套路徑理解所有 agent

Polylong

/opt/data 是 live state。

/opt/polylong-runtime 是 runtime overlay。

偏社群與記憶，所以資料邊界比 code 邊界更重要。

Asheron

/root/.hermes-asheron 是 profile。

/usr/local/lib/hermes-agent 是實際 Hermes install。

patch/scripts 會影響工具行為，不能只看 SOUL。

Aurelion

~/.hermes/profiles/aurelion 是 live profile。

cyclone-aurelion-hermes 是可追蹤 repo。

runtime 先跑，repo 要回補，避免 drift。

OpenAB On z-c

OpenAB 是控制面，不是第四隻角色龍

定位

OpenAB 在 z-c 上是 Cyclone 的 operations / code review / GitHub watch 控制面。

它負責讀 PR、追 issue、觸發 Codex review、把工作拆到正確 repo，而不是取代 Polylong、Asheron 或 Aurelion 的角色互動。

它應該做什麼

PR / issue watch Codex review Discord thread reporting Dashboard bridge Routing governance No secret output

一句話：OpenAB 是「幫 Cyclone 看 GitHub 與調度工作的營運代理」，三隻 Hermes Agent 則是各自的 Discord / runtime 工作角色。
