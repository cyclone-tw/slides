Foundation Models x Decision Making

自我改進代理

這篇論文的核心不是「再把模型做大」，而是把 foundation models 的知識與 decision making / RL 的互動學習合併，讓代理能規劃、接受回饋、修正自己，並降低對明確 reward 與人工監督的依賴。

184 頁Waterloo Master thesis，2025-08-25 上架
3 條路線VideoAgent、Reg-ReBoot、ReFeR

Thesis Map

一個問題

Foundation models 有知識但缺乏閉環行動；RL 有行動與回饋，但昂貴、窄任務、難泛化。論文主張兩者必須合流。

FM 的短板

大型模型擅長靜態資料上的知識遷移，但在真實互動場景中容易缺乏 agency、世界模型、長程規劃與從經驗修正的能力。

RL 的短板

強化學習能從環境回饋中產生目標導向行為，但通常需要大量互動資料、明確 reward、特定環境訓練，跨任務泛化較弱。

合流方向

用 foundation models 提供知識、表示與生成式模擬；用 decision making 提供互動、搜尋、回饋、自我改進。

Core Claim

三個回饋

三個研究看似不同，實際上都在回答同一件事：沒有完美 reward 或人工標註時，代理還能從哪裡得到學習訊號？

01 生成

模型先想像未來、生成計畫、產生推理軌跡或評估意見。

02 檢查

用 VLM、統計一致性、多代理評審等方式判斷輸出是否可靠。

03 選擇

把 test-time compute 轉成搜尋、比較、重排與更好的決策。

04 更新

把成功軌跡、 noisy CoT、結構化 feedback 變成訓練資料。

05 循環

讓 agent 能在行動、推理、評估三層逐步自我改進。

Reading Lens

怎麼讀

如果你是從產品或教育科技角度讀，重點不是機器人本身，而是「AI 如何在不完美回饋下形成更可靠的行動與判斷」。

給非技術讀者

可以把這篇看成三種「AI 自我修正」機制：看影片計畫並修正、從錯誤推理中學規律、讓多個模型互評後產生更穩的判斷。

給工程讀者

重點在 test-time compute 與資料瓶頸：推理時多算一點、產生候選、利用模型評估器，把不可得的 reward / verifier 替換成可取得的 proxy feedback。

Chapter 2

VideoAgent

把影片生成模型當成 embodied planning 的世界模型與 policy：先生成機器人任務影片，再用自我修正與 VLM 回饋讓影片更符合物理現實。

要解的問題

影片計畫能把語言指令轉成視覺軌跡，但常出現物體憑空消失、動作不合理、物理不連續，導致轉成 robot action 後失敗。

核心方法

VideoAgent 使用 self-conditioning consistency 讓模型反覆修正先前生成的 video plan，並用 VLM 作為 proxy reward 選出更可能成功的計畫。

自我改進

在線上執行後，成功軌跡被收集回來繼續 fine-tune，形成「生成計畫 → 執行 → 收集成功資料 → 改進模型」的循環。

Chapter 3

Reg-ReBoot

挑戰「一定要正確 CoT 才能訓練 reasoning」的直覺：只要錯誤推理裡仍保留一致的解題片段，模型可能學到有用的 reasoning primitives。

直覺反轉

錯誤答案的 CoT 不一定是垃圾。很多錯誤只是計算失誤或漏步，解題架構仍然合理，這些局部規律可被模型吸收。

理論類比

作者借用兒童語言習得的 regularization：孩子面對不一致輸入時，會抓住高頻、穩定的語法規律，而不是照抄所有錯誤。

訓練含義

SFT 在 noisy CoT 上不只是模仿答案，而是從大量不完美 trace 中平均掉局部錯誤，強化一致的推理模式。

Chapter 4

ReFeR

把生成式輸出的評估改造成「多模型 peer review」：小模型當 reviewer，大模型當 area chair，合成最後評分與文字回饋。

問題

BLEU、ROUGE、CLIPScore 等自動指標常和人類偏好不一致；人工評估又昂貴且不可擴展。

架構

多個 peer model 獨立給評論與分數，area chair model 讀取 peers 的意見後產生最終評估。類似學術審稿。

用途

除了評分，ReFeR 也產生結構化 feedback，可作為後續蒸餾與 fine-tuning 的訓練資料，形成 scalable oversight。

摘要譯解

近年的 AI 進展主要來自兩條路線：一是把大型 foundation models 用網路規模資料訓練到能產生文字、影像與影片；二是發展 decision making / reinforcement learning，讓系統透過經驗學習。單獨看，兩者都有明顯缺口；合併起來，才比較接近通往一般智慧的可擴展路徑。

RL 證明了互動式學習可以產生目標導向、自我改進，甚至超人類能力；但它很難從窄任務擴展到真實世界，因為資料稀少、回饋稀疏、reward 難設計。Foundation models 則擁有廣泛知識，卻缺少穩固的內部世界模型與行動閉環，因此規劃、推理與泛化仍受限制。

第 1 章：導論

作者把整篇論文定位在 FM 與 DM/RL 的交會處。FM 提供知識、常識與表徵；RL 提供行動、回饋與自我改進。真正的 autonomous agent 需要同時具備兩者：能理解世界，也能在世界中行動並從結果更新自己。

三個核心挑戰是：如何在推理時利用模型算力進行搜尋與規劃；如何用生成式世界模型模擬與練習；如何使用明確 reward 以外的回饋訊號。

第 2 章：VideoAgent

VideoAgent 把影片生成模型視為機器人任務的計畫器。輸入初始影像與語言目標後，模型生成未來影片，這個影片再轉換成控制動作。問題是生成影片常有 hallucination，例如物體位置不合理、物理不連續或目標沒有真正完成。

作者提出 self-conditioning consistency，讓模型學會根據先前生成結果進行修正；推理時再用 VLM 評估候選影片，選出較符合任務的計畫。若能在線上環境執行，成功軌跡會回流訓練，使生成模型更接近真實物理世界。

第 3 章：Reg-ReBoot

這章討論 LLM reasoning 的資料瓶頸。傳統做法依賴人工驗證、正確解題步驟或 rule-based verifier，但高品質 reasoning data 很難大量取得。作者提出一個反直覺觀點：錯誤的 CoT 也可能有訓練價值。

如果錯誤主要是局部計算或漏步，而整體解題結構仍合理，模型可以從大量 noisy traces 中抽取一致的 reasoning primitives。Reg-ReBoot 將這個現象理解為一種 regularization：模型平均掉分散的錯誤，保留高頻且一致的推理模式。

第 4 章：ReFeR

ReFeR 針對生成式模型評估。人工評估準確但昂貴，傳統自動指標便宜但常不符合人類偏好。ReFeR 借用學術 peer review：多個 peer model 先各自評估，area chair model 再整合評語與分數，給出最終判斷。

這個架構可以評估文字、影像、caption，也能遷移到 reasoning task。重要的是，它不只產生分數，也產生可用於後續 fine-tuning 的結構化 feedback。

第 5 章：結論

三個研究共同說明：自我改進不一定要依賴完美 reward、完整標註或人工監督。VideoAgent 從物理世界與 VLM 回饋學習；Reg-ReBoot 從不完美推理資料的統計結構學習；ReFeR 從多模型評審社群中產生可靠 feedback。

作者提出的長期方向是把三者合併成完整循環：agent 生成計畫、執行、用 ReFeR 類方法評估自己的計畫，再把回饋變成新訓練資料。這也是通往 AI scientist 或開放式自我改進系統的雛形，但安全與監督會變得更重要。
