Core Thesis

論文的主張很直接：模型要變成 agent，不能只靠靜態資料，也不能只靠手刻 reward。

白話版：Foundation Models 很會從大量資料學世界知識，但它們通常是「看過很多」而不是「真的會試、會改、會在環境裡學」。Reinforcement Learning 和 decision making 則擅長閉環行動與回饋學習，但常常需要明確 reward、模擬器、很多互動資料。這篇論文想把兩邊接起來。

這不是一篇只談概念的 agent 宣言。它把主張拆成三個可實驗的技術方向：影片世界模型與具身規劃、從不完美推理資料學 reasoning、以及用多模型評審機制做可擴展評估。

Three Pillars

三個核心工作，其實是在回答同一個問題：feedback 可以從哪裡來？

01

VideoAgent

把 goal-conditioned video generation 當作世界模型與行動計畫。模型先想像任務影片，再用 VLM feedback、反覆 refinement、online execution 讓計畫更合理。

Feedback 來源：物理世界、VLM 評估、執行結果。

02

Reg-ReBoot

挑戰「reasoning 一定要乾淨標準答案」的假設。它研究 LLM 是否能從未驗證、甚至最後答案錯的 CoT traces 裡，萃取穩定的推理模式。

Feedback 來源：不完美資料中的統計結構。

03

ReFeR

用多個 pretrained LLM/VLM 扮演 peers 與 area chair，像學術 peer review 一樣產生評分、理由與改進建議，降低人工評估瓶頸。

Feedback 來源：模型社群的審查與綜合判斷。

總覽摘要

這篇論文的核心，是把兩條 AI 發展路線重新接起來。第一條是 Foundation Models：靠大量靜態資料訓練，擁有廣泛知識、語言能力、影像理解與生成能力。第二條是 decision making / RL：透過行動、環境回饋、試錯、規劃與閉環學習，讓系統能朝目標改善行為。

作者認為，Foundation Models 雖然強，但很多時候缺少 grounding、agency 與自我改進機制；RL 雖然能學行動策略，但太依賴 reward 設計、模擬器與互動資料。真正可擴展的 agent，需要能用多種 feedback 學習：世界的物理結果、不完美資料裡的穩定結構、以及其他模型給出的評估與建議。

如果你做 robotics

先讀 Chapter 2。VideoAgent 展示影片生成模型如何變成具身任務的「想像與修正」機制。

如果你做 LLM reasoning

先讀 Chapter 3。Reg-ReBoot 關心的是：不完美 CoT 能不能仍然教會模型推理。

如果你做 AI evaluation

先讀 Chapter 4。ReFeR 把評估設計成多 agent 審查流程，接近 scalable oversight 的問題。

章節導讀

Chapter 1

導論：為什麼要統一 Foundation Models 與 Decision Making

這章先界定問題：FM 有知識與表徵能力，但缺少環境閉環；RL 有行動與改善機制，但資料效率與 reward 設計限制很大。作者把整本論文的共同線索定義為「用更廣義的 feedback 建立自我改進 agent」。

Chapter 2

VideoAgent：用影片世界模型做具身規劃

這是最具體的 embodied AI 工作。VideoAgent 先根據初始影像與語言目標生成影片計畫，再用 self-conditioning consistency 和 VLM feedback 修正幻覺與不合理物理。它也能透過環境執行回饋，把成功軌跡拿回來改善模型。

Chapter 3

Reg-ReBoot：從不完美 Chain-of-Thought 學 reasoning

這章挑戰乾淨資料崇拜。作者主張，若錯誤 CoT 的錯法足夠分散，而真正有用的推理步驟比較一致，next-token training 可能會放大穩定推理 primitive、平均掉雜訊。這讓 reasoning training 不一定完全依賴昂貴人工驗證或 rule verifier。

Chapter 4

ReFeR：用多模型審查做可擴展評估

這章處理 generative model 的評估瓶頸。ReFeR 把多個模型組成 peer review hierarchy，由 peers 給理由與分數，再由 area chair 綜合判斷。它可以評估文字、影像，也能延伸到 reasoning 任務。

Chapter 5

結論：把學習、搜尋、評估接成閉環

最後回到總主張：未來的 agent 需要同時能想像、行動、評估、修正。作者提出的自然延伸，是把 VideoAgent 類的世界模型與 ReFeR 類的自評估系統接起來，讓 agent 能連續產生資料、檢查計畫、改善自己。

1. 這篇論文想解決什麼問題？

近年的 AI 很大一部分進步來自 Foundation Models。它們透過大規模資料學到語言、影像、常識與抽象模式，因此能回答問題、寫程式、產生圖片、理解多模態內容。但這類模型大多是在靜態資料上訓練：資料已經存在，模型負責預測與生成。這讓它們很強，卻不一定真正理解行動造成的結果，也不一定能透過環境回饋持續改善。

另一條路線是 reinforcement learning 和 sequential decision making。這條路線關心的是：agent 在環境中採取行動、觀察結果、根據回饋更新策略。這比靜態預測更接近「會做事」的智慧。不過 RL 的痛點也很清楚：它需要大量互動、可靠 reward、可用模擬器，且常在特定任務上有效，跨任務泛化不一定好。

作者的總論點是：未來要走向自主、自我改進的 agent，不能只押其中一邊。Foundation Models 提供廣泛知識與生成能力；decision making 提供閉環學習、目標導向與行動能力。關鍵問題是，如何讓模型不只模仿資料，而是能用各種 feedback 修正自己。

2. Chapter 2：VideoAgent 的意義

VideoAgent 處理的是 embodied planning，也就是讓 AI 在具身環境中完成任務，例如機器人操作物體。傳統做法常需要 action label 或明確 reward，但這些資料很貴。VideoAgent 的想法是：如果模型能生成「任務應該如何發生」的影片，它就能先在想像中規劃，再把影片轉成行動。

問題是，影片生成模型容易 hallucinate。它可能生成看起來合理但物理上不成立的畫面，例如物體消失、手臂穿模、目標沒有真的完成。VideoAgent 因此引入 refinement：模型不是只生成一次，而是反覆修正影片計畫。修正過程使用 self-conditioning consistency，並透過 Vision-Language Model 判斷計畫是否符合任務與物理常識。

更重要的是，VideoAgent 不只 offline 生成影片。當影片計畫被拿去執行後，系統可以收集環境裡的結果，把成功經驗再餵回模型。這讓它接近一個自我改進 loop：想像、執行、觀察、再改善。論文在 Meta-World、iTHOR 與真實機器人影片資料上展示，這種 feedback-guided refinement 可以降低 hallucination，並提升任務成功率。

3. Chapter 3：Reg-ReBoot 的意義

Reg-ReBoot 轉向 LLM reasoning。一般提升 reasoning 的方法，常依賴高品質資料：人工驗證的解題過程、正確答案、rule-based verifier，或 RL 訓練流程。這些方法有效，但成本高，也限制了可擴展性。

作者提出一個反直覺問題：如果 Chain-of-Thought 資料沒有被驗證，甚至有些最後答案是錯的，模型仍然能學到 reasoning 嗎？Reg-ReBoot 的答案偏向肯定。它的核心假設是：錯誤資料裡可能同時存在兩種成分，一種是分散、個別、隨機的錯誤；另一種是反覆出現、穩定、有用的推理 primitive。當模型用大量資料做 next-token training 時，穩定模式會被學起來，分散錯誤則可能被平均掉。

這個觀點把「不完美資料」從垃圾資料改看成廉價但有訊號的訓練來源。它不代表資料品質不重要，而是提醒我們：reasoning 的可擴展訓練，不一定只能靠昂貴的 gold solution。對想做 agent self-improvement 的人來說，這很關鍵，因為 agent 在真實世界裡產生的中間推理與嘗試，通常不會天然乾淨。

4. Chapter 4：ReFeR 的意義

ReFeR 處理的是 evaluation 與 oversight。生成模型越強，越需要可靠評估；但人工評估昂貴、慢、不易規模化，傳統自動指標又常和人類偏好不一致。ReFeR 的做法是把評估流程設計成一個多 agent peer review system。

在 ReFeR 裡，多個 pretrained LLM 或 VLM 先扮演 peers，分別分析輸出品質、提出理由與評分；接著由 area chair 模型整合 peers 的意見，做最後判斷。這個 hierarchy 類似學術審查：不是只問單一模型「好不好」，而是讓多個模型提供視角，再做綜合。

論文把 ReFeR 用在文字生成、影像品質、reasoning tasks 等場景，並提出 ReFeR-Pro 與 ReFeR-Lite 兩種版本。Pro 偏重更高性能與更多推理計算，Lite 偏重成本與 compute efficiency。作者的關鍵主張是：模型不只可以生成內容，也可以提供結構化 feedback；這些 feedback 又能被拿來 distill 或 fine-tune 後續模型，形成改進材料。

5. 最後的統一觀點

VideoAgent、Reg-ReBoot、ReFeR 看起來分別在 robotics、LLM reasoning、evaluation，但它們共享同一個架構問題：agent 如何在沒有完美標註、沒有明確 reward、沒有無限人工監督的情況下改善自己？VideoAgent 用物理世界與 VLM feedback，Reg-ReBoot 用不完美推理資料裡的統計結構，ReFeR 用模型社群的審查與綜合判斷。

這篇論文最值得帶走的，不是某個單點方法，而是一個工程方向：自我改進 agent 需要 feedback plumbing。也就是說，系統要能產生候選行動或答案，取得某種評估訊號，將訊號轉成可學習資料，並把改善後的能力再放回下一輪行動。

6. 對 AI workflow / agent system 的啟發

如果把這篇論文放回實務 AI workflow，它提醒我們不要只問「模型夠不夠大」。更實際的問題是：系統有沒有閉環？有沒有紀錄失敗？有沒有把 review 變成訓練資料或 prompt 改進？有沒有把多個模型或工具的評估結果組織成可靠決策？

對 agent 工程來說，這篇論文可視為三個模組的研究版藍圖：world model 負責想像與規劃，reasoning bootstrap 負責從不完美軌跡學習，evaluation society 負責 scalable oversight。真正困難的地方，是把這些模組接成穩定、安全、可驗證的長期自我改進系統。

關鍵概念詞典

概念白話解釋在論文裡的角色
Foundation Model 用大規模資料預訓練出的通用模型，例如 LLM、VLM、影片生成模型。 提供廣泛知識、生成能力與先驗。
Decision Making 讓系統在狀態、行動、回饋之間做連續決策。 補上目標導向、行動與閉環學習。
World Model 模型內部用來預測「如果這樣做，世界接下來會怎樣」的機制。 VideoAgent 用生成影片當作可視化的世界模型。
Test-Time Compute 不是只靠訓練時學到的東西，而是在回答或行動當下多花計算做搜尋、評估、修正。 VideoAgent 與 ReFeR 都把更多推理時間轉成更好的輸出。
Chain-of-Thought 模型解題時寫出的中間推理步驟。 Reg-ReBoot 研究不完美 CoT 是否仍能提供 reasoning 訊號。
Scalable Oversight 當人類無法逐一檢查所有輸出時，用可擴展方法維持評估與監督品質。 ReFeR 用多模型審查降低人工評估瓶頸。
