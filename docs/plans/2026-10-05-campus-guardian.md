# 校園守護者：教師資安情境簡報

Tracking: https://github.com/cyclone-tw/slides/issues/11

## 已確認範圍
將使用者初稿重新規劃為 HTML 情境選擇簡報。B 版明亮像素校園、教師本人為主角、貓頭鷹解說。教師 Q 版頭部較最後測試圖略小。除封面指定日期外，不顯示時長、倒數、分數、血量或多餘提醒。來源放解說末尾。使用者已批准完整製作，並於本機驗收後明確授權公開發布與 Wiki 講稿歸檔。

## 內容與來源
場景：假冒熟人、假驗證、AI 與資料、登入驗證、第三方權限、BYOK、雲端分享、金鑰外洩、已執行指令、教學持續、共用設備、學生影像保護。全部角色與事件皆為虛構。官方文件詳見 campus-guardian/src/content.js。新聞日期與個案事件時間線不進畫面。教學持續活動是教學設計，不宣稱特定平台故障原因。

## 設計
色彩：墨藍 #183953、天空藍 #c9e8fa、黑板綠 #226f72、紙白 #f8fcff、木金 #e8bd78、失敗紅 #943b49。
字體：PingFang TC / Microsoft JhengHei，投影大字；像素風由場景、角色、硬邊框建立，不犧牲中文可讀性。
布局：全景校園背景；左側角色，右側不透明淺色對話面板。封面使用大標題與教師／貓頭鷹。選項與解說分開，單畫面單一判斷。手機改為角色小景在上、內容自然往下捲動。

## 互動契約
cover → intro → question → wrong → question，或 question → lesson → lesson → next intro。每個錯誤選項有專屬後果，不扣分；未答對時一般前進鍵不能跳關。章節選單供講師主動跳頁。重試維持題目及選項順序。返回、鍵盤、全螢幕與本機續播皆需可用；不收集任何輸入資料。

## 產物
src 下維護 HTML、CSS、JS；Python 標準函式庫打包成包含圖片的單一 index.html，不需網路、套件或伺服器。來源連結的外部文件需連網。PNG 原圖保留；全為 imagegen 原創示意素材。

## 驗收
逐題測試所有選項、重試、解說、來源與返回。檢查桌面、手機、低高度螢幕，無水平溢出、主要按鈕無裁切；檢查 file:// 離線啟動、鍵盤、章節導航、本機儲存不可用時降級。QA 截圖留 slides-local，避免入 repo。已交付本機檔案，並依後續授權透過 PR #12 發布至 GitHub Pages。

## 使用者後續修訂
封面改為「校園資通安全與數位防護實務」，校名國姓國小、日期 2026-10-07。此為先前無日期限制的明確例外；其餘內容維持原約定。

## 發布後整理（#13）

首頁以 HTML date metadata 優先取得場次日期，資料夾推算作為後備；靜態索引與即時發現採相同規則。保留既有續播儲存鍵；舊版 Safari 不列支援範圍。驗證日期在靜態與即時索引一致，並確認原有資料夾日期後備仍可用。
